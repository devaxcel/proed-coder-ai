=====================================================================
SCHEMA CHANGE NEEDED — edit your EXISTING User model, don't paste a
new one. This is a one-field addition, not a new model.
=====================================================================

Open prisma/schema.prisma. Find your existing User model — it currently
looks like this:

model User {
  id            String    @id @default(cuid())
  email         String    @unique
  name          String?
  emailVerified DateTime?
  image         String?
  role          UserRole  @default(CODER)
  createdAt     DateTime  @default(now())

  accounts  Account[]
  sessions  Session[]
  auditLogs AuditLog[]
  queryForms QueryForm[]
}

Add ONE line — `passwordHash` — right after the `role` line, so it
becomes:

model User {
  id            String    @id @default(cuid())
  email         String    @unique
  name          String?
  emailVerified DateTime?
  image         String?
  role          UserRole  @default(CODER)
  passwordHash  String?
  isActive      String?
  createdAt     DateTime  @default(now())

  accounts  Account[]
  sessions  Session[]
  auditLogs AuditLog[]
  queryForms QueryForm[]
}

That's it — one line added, nothing else in the model changes.

After saving, run:
  npx prisma generate
  npm run db:push
